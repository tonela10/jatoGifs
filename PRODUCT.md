# jatoGifs

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Confirmed in the approved plan: Chromium Manifest V3, plain JavaScript, HTML and CSS; no framework or backend.

## Users
GitHub users composing issues, pull requests, reviews and discussions who want to insert the owner's tonela10 reaction GIFs.

## Product Purpose
Type /gif, choose a GIF, and insert image Markdown without losing the draft or submitting it.

## Capabilities and Constraints
Only github.com conversation editors. Anyone can submit GIPHY IDs at jato.sediles.dev; only the owner can remove entries; Cloudflare D1 stores only GIPHY IDs. The extension reads the current public list when the picker opens and fetches GIF data directly from GIPHY. No baked-in GIF catalogue, media files or media URLs. The initial database migration preserves the nine GIFs from 1.1.1. Manual browser installation; no paid service setup.

## Brand Commitments
Exact name: jatoGifs. Spanish interface. Compact, accessible gallery that fits GitHub light and dark themes, as approved in the plan.

## Evidence on Hand
Channel observed on 2026-10-29 with eight GIFs. The user's beta application key returns all eight via Get GIFs by ID; search @tonela10 returns zero. The user rejected sending support and then chose the manual ID solution rather than submitting Creator. jatoGifs was installed in their usual Brave profile. No store registration, external submission or payment. No promotional claims or invented usage metrics.

## Accessibility & Inclusion
Keyboard selection, visible focus, Escape to dismiss and status announcements.
