Privacidad de jatoGifs

Versión 1.3.0 · 12 de noviembre de 2026

Texto de GitHub

jatoGifs procesa localmente el texto y la posición del cursor de los editores de conversación de github.com para detectar /gif y sustituirlo por Markdown. El borrador y el nombre del repositorio no se envían al desarrollador ni a GIPHY. La extensión no solicita contraseñas, cookies ni tokens de GitHub.

Conexiones con GIPHY

El navegador carga imágenes públicas de media.giphy.com con los ID del catálogo. La extensión no usa la API de GIPHY ni envía una clave, token o referencia a la página del borrador. GIPHY recibe la información de red necesaria para responder. Consulta su política de privacidad.

Catálogo compartido

La extensión solicita la lista pública de ID en jato.sediles.dev, alojado en Cloudflare. No envía cookies, claves, borradores ni el nombre del repositorio al catálogo. El servicio recibe los datos de red necesarios para responder. Cualquiera puede añadir un GIF desde la web. Cloudflare usa la dirección IP de la solicitud para limitar intentos de alta; la dirección no se guarda en la base del catálogo. Solo el propietario inicia sesión para quitar GIF.

Almacenamiento

La extensión no guarda claves. Al actualizar desde una versión anterior borra la clave de GIPHY que hubiera quedado guardada por jatoGifs. Los ID del catálogo abierto se mantienen en memoria de sesión para paginar y se eliminan al cerrar el selector. La extensión no guarda archivos GIF, URL multimedia ni borradores de forma persistente. La lista local de una versión anterior, si existe, puede consultarse desde Configuración para copiar sus enlaces al panel.

Imágenes en comentarios

Al elegir un GIF, se inserta una URL externa en tu borrador. Cuando tú publicas el comentario, GitHub y quienes puedan verlo pueden acceder a esa URL. La imagen continúa alojada en GIPHY; su disponibilidad depende de ese servicio.

Analítica y permisos

jatoGifs no incorpora analítica propia, publicidad ni seguimiento del historial. Solo se ejecuta en GitHub. Consulta el catálogo de jato.sediles.dev y permite cargar imágenes de media.giphy.com. No lee el portapapeles.
