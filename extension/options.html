jatoGifs

El selector usa el catálogo compartido de jatoGifs. Los cambios aparecen al volver a escribir /gif. No necesitas una cuenta ni una clave de GIPHY.

Insertar un GIF

Abre un comentario, issue, pull request o Discussion en github.com y escribe /gif. Elige con el ratón o las flechas y pulsa Enter. Esc cierra el selector.

El GIF se verá en la previsualización y al publicar. jatoGifs no envía el comentario por ti.

Si no aparecen GIF

Pulsa «Comprobar catálogo» para revisar el catálogo. Si un GIF deja de estar disponible en GIPHY, el propietario puede quitarlo desde el panel web.
